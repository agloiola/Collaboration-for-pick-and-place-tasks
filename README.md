# Cooperação entre Robô Móvel (UGV) e Braço Robótico para Tarefas de Pick and Place

Este repositório apresenta a implementação utilizada no artigo **"Collaboration between UGV and robotic arm for pick and place tasks"**.

O projeto demonstra um sistema cooperativo entre um robô móvel terrestre (UGV) e um braço robótico. Nesse sistema, o robô móvel se desloca até uma posição pré-definida e o braço robótico realiza uma tarefa de **pick and place**, retirando um objeto de uma superfície e posicionando-o sobre o robô móvel.

No projeto foram utilizados:
- **Robô móvel:** TurtleBot3  
- **Braço robótico:** WidowX 250S

A implementação foi realizada utilizando **ROS Noetic**, **Gazebo** para simulação e **MoveIt** para planejamento de movimento do manipulador.
